# Homemade Food Ordering Website

## Overview

This is a food ordering web application built using React + Vite as the frontend framework. It allows users to browse homemade food items, place orders, and manage their cart. The project integrates Firebase for authentication, and uses React Hook Form for handling form inputs efficiently.

## Features

- User Authentication with Firebase (Sign up, Login, Logout)
- Food Menu display with Bootstrap styling
- Cart Management (add, remove, update items)
- Order Placement with form validation using React Hook Form
- Responsive Design using Bootstrap and React Bootstrap

## Tech Stack

- React + Vite
- Bootstrap / React Bootstrap
- React Hook Form
- Firebase
